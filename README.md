# global-olympic-sports-analysis
Data analytics project exploring historical Olympic medal-winning athlete records using Tableau.


## Project Overview
This project analyzes historical Olympic athlete and medal records using Tableau.

## Objectives
- Identify the top 10 NOCs by medal-winning athlete records.
- Compare medal-winning athlete records across sports.
- Explore trends across Olympic years.
- Present findings through a Tableau dashboard and story.

## Dataset
Source: [120 Years of Olympic History – Athletes and Results](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

The dataset covers Olympic Games from 1896 to 2016.

## Tools Used
- Tableau Public
- CSV dataset
- GitHub

## Visualizations
1. Top 10 NOCs by medal-winning athlete records
2. Medal-winning athlete records by sport
3. Trends in medal-winning athlete records over time

## Limitations
The dataset ends in 2016. The counts represent athlete-event records, not unique individual medals.
